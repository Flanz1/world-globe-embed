        Slots

        Each slot is one embed. Switching a slot's map goes live when the deploy finishes (allow up to ~10 minutes for GitHub Pages caching).

        A slot is one embed address (/v/<slot>/) showing one of the maps.

        An equirectangular map, ideally twice as wide as tall (square to 4:1 works).

        Size tips

        Pole padding fills any space above and below the map. Bigger maps stay sharp when zoomed in: 8192 px wide or more gets an extra-sharp version, and 16384 or 32768 px wide also gets close-up detail. Maps over 16384 px wide are uploaded unchanged, so save them as JPEG (quality 80–90) and keep them under 100 MB.
