Paste your own GitHub token. It's sent only to api.github.com and, unless you tick Remember, forgotten when you close this tab.

  • Repository owner: a fine-grained token limited to this one repository, with Contents: Read and write (and optionally Actions: Read-only).
  • Collaborators: GitHub doesn't let fine-grained tokens write to a personal account's repository you're only a collaborator on, so create a classic token with only the public_repo scope and a short expiry.

Only tick Remember on your own computer: a remembered token stays in this browser until you press Forget token.

    Upload a map

    An equirectangular map, ideally twice as wide as tall. Anything from square to 4:1 works, and pole padding fills the rest. Bigger maps stay sharp when zoomed in: 8192 px wide or more gets an extra-sharp version, and 16384 or 32768 px wide also gets close-up detail. Maps over 16384 px wide are uploaded unchanged, so save them as JPEG (quality 80–90) and keep them under 100 MB.
