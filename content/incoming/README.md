# Drop new maps here

Upload an equirectangular PNG, JPEG or WebP (2:1 such as 4096×2048 looks best; anything from 1:1 to 4:1 is accepted) into this folder.
The **Process maps** workflow converts it, removes it from here, and creates `content/maps/<name>.json`.
The file name becomes the map id: `Aerthos v2.png` → `aerthos-v2`.
